* **Single-frame inputs & Side Effects:** When testing single-frame input consumption (like `squeakPressed = true`) or side-effects on entities (like modifying bird `vy`), use the HTML test harness (`test_runner.html`) to inject state directly and `await` a short timeout (e.g. `setTimeout(r, 200)`) for the game loop to process it, then assert that the input flag was cleared and the side-effect applied.
